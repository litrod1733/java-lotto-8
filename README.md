# 로또 (우테코 프리코스 3주차)
구입 금액으로 로또를 자동 발행하고, 입력받은 당첨 번호와 보너스 번호를 기준으로 등수/수익률을 계산하는 콘솔 프로그램입니다.<br>
**JDK 21**에서 실행 가능하며, 미션 가이드를 준수합니다(메서드 <= 15라인, indent depth <= 2, `else` 금지, `Enum` 사용, `[ERROR]` 메시지 규칙 등).

## 학습/구현 목표
- 연관 함수들을 클래스로 묶고, 객체 간 협력을 통해 기능을 완성한다.
- 단위 테스트를 통해 의도한 동작을 검증한다.
- 2주 차 피드백을 반영한다.
---
## 실행 방법
```bash
# Java 버전 확인 (21)
java -version

# 테스트 실행 (Mac/Linux)
./gradlew clean test

# 애플리케이션 실행
./gradlew clean run
```

> **주의**

> - "프로그램 종료에 `System.exit()`사용 금지."
> - "패키지/파일명 임의 변경 금지(문서에서 허용한 범위 외)."

## 프로그램 규칙 요약
- 로또 한 장: **1~45 범위**의 **서로 다른** 정수 **6개, 오름차순** 출력
- 당첨 판단
  - 1등: 6개 일치 (2,000,000,000원)
  - 2등: 5개 일치 + 보너스 (30,000,000원)
  - 3등: 5개 일치 (1,500,000원)
  - 4등: 4개 일치 (50,000원)
  - 5등: 3개 일치 (5,000원)
- 로또 가격: **1,000원/장**, 구입 금액만큼 자동 발행
- **수익률** = (당첨 총 상금 / 구입 금액) * 100, **소수점 둘째 자리에서 반올림**
- 모든 예외 메시지는 `[ERROR]`로 시작

## 기능 목록 (커밋 단위)
- [ ] **금액 입력/검증**: 숫자, 양수, 1,000원 단위 확인
- [ ] **로또 자동 발행**: 개수 = 금액/1000, 중복 없는 6개 생성, 오름차순 정렬
- [ ] **당첨 번호 입력/검증**: `,`구분 6개, 범위/중복/개수 확인
- [ ] **보너스 번호 입력/검증**: 범위 확인, 당첨 번호와 중복 금지
- [ ] **등수 판별 Enum(Rank)**: (매칭수, 보너스) -> 등수/상금
- [ ] **결과 집계(Result)**: 등수별 카운트, 총 상금
- [ ] **수익률 계산**: 소수점 둘째 자리 반올림 후 `%`포맷
- [ ] **출력 형식**: 구매 결과, 당첨 통계, 수익률
- [ ] **예외 처리 정책**: `[ERROR]`로 시작, 잘못된 입력 . 재입력
- [ ] **단위 테스트**: Rank/Result/검증/Generator/채점 로직

## 설계 개요
- **패키지**: `application`, `domain`, `view`, `support`
- **주요 도메인**
  - `Lotto`(제공): numbers 6개 검증만
  - `LottoTicket`: 한 장 래핑, 매칭/보너스 판별
  - `WinningNumbers`, `BonusNumber`
  - `Rand (Enum)`: 상금/판별
  - `Result`: 집계,수익률
  - `Generator`/`RandomLottoGenerator`(missionutils 사용)
- **흐름**
  1. 금액 입력 -> 발행 개수 계산/발행
  2. 발행 목록 출력
  3. 당첨 번호/보너스 입력
  4. 채점,집계 -> 통계/수익률 출력
